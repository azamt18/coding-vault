# .NET Intermediate Mentoring — Multithreading

Hands-on multithreading exercises in C# covering Tasks, Threads, ThreadPool, synchronization primitives, and parallel operations.

## Tasks

| # | Topic |
|---|-------|
| 1 | Create 100 Tasks and wait for all to finish |
| 2 | Task chaining with `ContinueWith` |
| 3 | Matrix multiplication — sequential vs parallel (`Parallel.For`) |
| 4 | Recursive thread creation using `Thread` + `Join` and `ThreadPool` + `SemaphoreSlim` |
| 5 | Two-thread shared collection with `AutoResetEvent` synchronization |
| 6 | Task continuations with `TaskContinuationOptions` |

## Requirements

- .NET 6+
- Visual Studio or Rider
