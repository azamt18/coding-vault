# Yangi Yozuv

Browser extension that converts Uzbek words to the new Latin alphabet as you
type: `sh→ş`, `ch→ç`, `oʻ→ö`, `gʻ→ğ`. The alphabet law (O'RQ-1184) takes
effect on 22 April 2027.

Everything runs locally. The extension makes no network requests.

## How it works

- A word is converted when you finish it with a space, punctuation or Enter.
  Enter is handled separately because chat apps send the message on Enter.
- English words (a bundled SCOWL list of ~3,100 words containing sh/ch), links,
  emails, @handles, #hashtags and camelCase brands are left alone.
- One Backspace right after a conversion restores what you typed.
- Works by default on `.uz` sites, Telegram Web, Gmail, WhatsApp Web, Facebook,
  Instagram, X, LinkedIn, YouTube, Outlook, ChatGPT, Gemini and Claude.
  Other sites are turned on from the popup. Google Docs isn't supported.

## Layout

| Path | What it is |
|---|---|
| `src/core/` | Converter and typing logic. No browser code, so it can be ported to Kotlin/Swift with the same test cases. |
| `src/core/data/english-words.json` | Generated by `npm run build:words`. |
| `src/entrypoints/content.ts` | Watches typing in text fields and applies conversions. |
| `src/entrypoints/background.ts` | Starts the extension on sites the user adds. |
| `src/entrypoints/popup/` | Settings popup (Uzbek, new alphabet). |
| `store/` | Store listing text and graphics. |

## Commands

```bash
npm install
npm test            # unit tests (converter + typing logic)
npm run test:e2e    # builds, then types into real fields in Chrome for Testing
npm run compile     # type check
npm run dev         # opens Chrome with the extension loaded, reloads on save
npm run zip         # builds .output/yangi-yozuv-<version>-chrome.zip for the store
npm run store:graphics  # regenerates store screenshots
```

## Publishing to the Chrome Web Store

1. Register at https://chrome.google.com/webstore/devconsole (one-time $5 fee;
   Google may ask for identity verification).
2. Run `npm test && npm run test:e2e && npm run zip`.
3. **New item** → upload `.output/yangi-yozuv-0.1.0-chrome.zip`.
4. Fill in the store listing and privacy tabs from `store/LISTING.md`.
5. Host `PRIVACY.md` publicly and paste its URL in the privacy tab.
6. Submit for review. New extensions usually take from a few hours to a few days.

Edge, Opera and Yandex Browser can install from the Chrome Web Store. Edge also
has its own store (Partner Center) if you want a separate listing later.
